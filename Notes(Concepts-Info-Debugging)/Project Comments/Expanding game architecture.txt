2) Create a Pacman class (would be in the pacman.py file)
- Similar to the snake class, code snippet can look like this:

class PacMan:

    def __init__(self):
        self.rect = pygame.Rect(100,100,20,20)
        self.direction = "RIGHT"


    def move(self):

        if self.direction == "RIGHT":
            self.rect.x += 20

        elif self.direction == "LEFT":
            self.rect.x -= 20

- There is simiilarity when noticing code,
