PAC-MAN MAZE SYSTEM STATUS

Completed:

1. Grid System
- Game window: 600x600 pixels
- Tile size: 20x20 pixels
- Maze uses a 30x30 tile grid


2. Border Wall Generation
- Creates walls around the entire game window.
- Prevents Pac-Man and ghosts from leaving the screen.
- Stores walls inside the maze wall list.


3. Ghost House Generation
- Creates a centered ghost starting area.
- Stores ghost house walls separately from normal maze walls.
- Will later be used for ghost spawning and movement.


4. Pellet Generation
- Creates pellets throughout the maze.
- Stores all pellets inside a pellet list.
- Pac-Man will remove pellets when collected.


5. Maze Collision System
- Maze handles collision checking using is_wall().
- Pac-Man does not directly check every wall.
- This keeps responsibilities separated and allows easier dynamic maze generation later.


Current Maze Structure:

Maze
 |
 |-- Border Walls
 |
 |-- Ghost House
 |
 |-- Pellets
 |
 |-- Collision Detection
